# FO Gate — Feedback Ops HITL MCP

Classify client feedback into Notion Inbox + Tasks, draft the reply, and refuse to send until a human says so.

This branch is the **Build** of [PR #7 VALIDATE.md](VALIDATE.md). Draft only. **Do not merge. Do not publish to the MCP registry or Chrome Web Store.**

`sent` stays `false` until a buyer writes **send is on**. This MVP still has **no `send_reply` tool**.

Not Verde. Not Gmail. Not live SMTP.

## How to demo locally

Node 18+. No `npm install`. No secrets. No Docker.

```bash
git clone https://github.com/nicholas-morales/feedback-ops-copilot.git
cd feedback-ops-copilot
git checkout cursor/fo-gate-mcp-seats-5663
npm test
npm start
```

Then open:

- Landing: http://127.0.0.1:8787
- Pricing: http://127.0.0.1:8787/pricing
- Health: http://127.0.0.1:8787/health

On the landing, paste a ticket and click **Classify** or **Run HITL loop**. That POSTs JSON-RPC to `/mcp` (`classify_feedback` → `upsert_inbox_item` → `upsert_task` → `get_send_gate`).

### Stdio MCP (Cursor local)

```bash

```

Install deeplink (prompts Cursor — not a Marketplace submit):

`https://cursor.com/install-mcp?name=FO%20Gate&config=` + base64 of that command/args object. Generated by `src/mcp/cursor-link.mjs`.

### One-shot classify (no network Notion)

```bash
node bin/fo-gate.mjs classify samples/billing.example.json
node bin/fo-gate.mjs classify samples/empty-body.example.json
```

Empty body → Category Ambiguous, **no Task**, Retries row unresolved, `sent: false`.

Approved sample (`samples/approval-approved.example.json`) → Status Approved, Approval needed off, **`sent` still false**.

## MCP tools

| Tool | Does | Must not |
| --- | --- | --- |
| `classify_feedback` | Category + Priority + summary | Call Gmail / train a model |
| `upsert_inbox_item` | Inbox row | Create a Task for empty-body hold |
| `upsert_task` | Related Task + reply draft | Flip send |
| `list_awaiting_approval` | Waiting-approval tasks | Auto-approve |
| `log_exception` | Retries row | Retry send |
| `get_send_gate` | `{ sent: false, send_is_on: false }` | Expose `send_reply` |

Hosted mode (`FO_GATE_MODE=hosted`) requires `Authorization: Bearer <key>` matching `FO_GATE_LICENSE_KEYS`. Unlicensed calls return **401** and write nothing. Local / stdio is SKU A ($0).

Live Notion writes stay off unless `FO_GATE_NOTION_WRITES=1` **and** a token is set. Default: in-memory store only.
