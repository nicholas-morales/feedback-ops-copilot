# How to paste this kit into Freelancer.com (free UI only)

**Draft kit.** Nick pastes after FO blast. No publish pressure from this file. No merge. No bids. No paid Connects, bid packs, memberships, Highlight/Sponsor/Sealed, featured ads, or Preferred Freelancer.

Official map: [Editing my profile](https://www.freelancer.com/support/profile/how-to-edit-your-profile) · [Getting started (headline / summary / rate)](https://www.freelancer.com/community/articles/a-freelancer-s-guide-to-freelancer-com-getting-started) · [Fees (do not buy)](https://www.freelancer.com/feesandcharges).

Copy lives in [FREELANCER-PASTE.md](./FREELANCER-PASTE.md). Checkbox pass: [FIELD-CHECKLIST.md](./FIELD-CHECKLIST.md).

## 0. What this kit is (and is not)

| This kit | Not this kit |
| --- | --- |
| Paste headline, Summary, skills, portfolio, experience | Place bids / auto-apply |
| Optional bid **templates** Nick may use later by hand | Project Catalog / Services listings |
| Free View Profile → Edit Profile | Membership, extra bids, cover photo |
| Proof URL on the profile | Amplemarket, scrape, Contra outbound (that is **Parallel**) |

Freelancer.com does **not** use Upwork **Connects**. Do not buy Connects packs for this work. Do not buy Freelancer bid bundles either. Free members already receive a small monthly bid allotment ([6 bids/month](https://www.freelancer.com.au/faq/question.php?code=bid-limit), replenished slowly). **This kit does not spend those bids** and does not tell you to top them up.

## 1. Open the editor (2 minutes)

1. Sign in at [freelancer.com](https://www.freelancer.com).
2. Click your **profile picture thumbnail** (main menu, usually top right).
3. Click **View profile**.
4. Click **Edit Profile**.
5. Ignore any **Membership**, **Upgrade**, **Preferred Freelancer**, **Get more bids**, **Highlight**, **Featured**, **Cover photo**, or card-checkout modal. Close it.

Parts on Edit Profile: **Hourly Rate**, **Professional Headline**, **Top Skills**, **Summary** ([support](https://www.freelancer.com/support/profile/how-to-edit-your-profile)).

Toggle **View Freelancer Profile** (not Client) when you preview.

---

## 2. Professional Headline + Summary

1. **Professional Headline** → paste the locked 40-character line from the paste pack.
2. **Summary** → paste **Overview A**. Use **B** only if the box still looks empty after save.
3. Do not type a dollar amount.
4. **Save** if this screen has its own save control (some blocks save per section).

If a field rejects the slash in `TypeScript / Next.js`, use the 38-character fallback headline.

---

## 3. Top Skills

1. Still on **Edit Profile → Top Skills**.
2. Add the eight locked skills **in order**. Choose preload tags when they appear.
3. If `Vercel`, `AI agents`, `Cursor`, or `API integration` have no tag, skip that tag — Summary already carries the words.
4. Stop at eight. Do **not** upgrade membership to unlock more skill slots ([membership page](https://www.freelancer.com/membership/) is a paid upsell — close it).

---

## 4. Hourly Rate — leave it

1. Look at **Hourly Rate**. Do not type `$75–$120`.
2. If empty, leave empty.
3. If a number is already there, leave it until Nick names option A / B / C.
4. If Save is blocked until a number exists, keep the existing figure and do not invent a new floor.

Rate options stay in the paste pack. They are not live.

---

## 5. Portfolio (proof URL)

1. From **View Profile**, click **Manage Portfolio**.
2. Click **Add or edit items**.
3. **+ Add Item** (or Edit on an empty card).
4. Title → `Feedback Ops Copilot`.
5. Description → portfolio blurb from the paste pack (includes the URL).
6. If a website / URL field exists, paste `https://feedback-ops-copilot.vercel.app`.
7. File: skip, or upload a still Nick already has. Article-only is fine.
8. **Save** → **Go back to Profile page**.

Do not add extra portfolio **categories** (paid-membership perk). Do not upload repo zips or anything with secrets.

---

## 6. Experience (Applied AI Ops)

1. Stay on **View Profile** and scroll to the **resume** blocks (Experience, Education, …).
2. **Experience** → add / edit.
3. Company → `Applied AI Ops`. Title → locked headline. Location → Los Angeles / remote.
4. Description → experience block from the paste pack.
5. **Save** on that block only.

Skip Education, References, Qualifications, Publications, Certifications, Articles, and Skills Tests.

---

## 7. Photo + location (free only)

1. On **View Profile**, if the avatar shows a **pencil**, upload Nick’s existing headshot (clear, shoulders-up). Do not generate a new one from this kit.
2. **Cover photo** requires a **paid membership** ([support](https://www.freelancer.com/support/profile/how-to-edit-your-profile)). Leave the default banner.
3. Account / settings (if you need city): country **United States**, city **Los Angeles**. Do not buy a username change.

Email verification is free and fine if not already done. Skip paid “Verified by Freelancer” / identity upsells.

---

## 8. Preview, then stop

1. View Profile → **View Freelancer Profile**.
2. Confirm: headline, Summary A or B, skills, FO portfolio item, Applied AI Ops experience, proof URL visible, no cover-photo badge, no membership badge you just bought.
3. Hourly Rate is empty or unchanged.
4. **Stop.** Do not open Browse Projects to spray bids. Do not create a Service / Project Catalog listing. Do not run Amplemarket. FO Contra outbound is Parallel.

Proposal templates in the paste pack are for a **later, manual** bid after Nick **OK** — not a step in this how-to.

---

## 9. If Nick later bids by hand (still unpaid)

Only after **OK**. Still no auto-apply.

1. Open the project → read it. Confirm it is FO-adjacent (inbox/ops/Notion/Vercel demo/HITL), not a random Next.js contest.
2. Confirm you already have **one matching skill** (required to bid).
3. Bid amount + days from the matching template (199/3, 399/5, or 500/2).
4. Paste the short proposal. Swap the first line so it mirrors *their* post.
5. One milestone (or 50/50 on founding). Total equals the bid.
6. **Optional Upgrades: leave every box unchecked** (Highlight, Sponsor, Sealed).
7. Do **not** click Place Bid unless Nick is the one submitting.
8. If the UI says you are out of bids, **stop**. Do not buy a pack or membership.

## FAQ

**The UI labels differ from this doc.**  
Match by meaning: Headline, Summary, Top Skills, Hourly Rate, Manage Portfolio, Experience. Support still lists those four Edit Profile fields.

**Should I spend the six free bids to “warm up” the account?**  
No. This kit does not spend bids.

**Can I paste $75–$120 into Hourly Rate as a range?**  
No. Unconfirmed, and the field is a single number.

**Does this send Contra messages?**  
No. Profile copy only. Contra is Parallel.

**Do I need a minimum wallet balance to edit the profile?**  
No. A minimum balance is a bidding/fees concern ([fees](https://www.freelancer.com/feesandcharges)). Do not add funds from this kit.
