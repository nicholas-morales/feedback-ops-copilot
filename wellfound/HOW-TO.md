# How to paste this kit into Wellfound (free UI only)

**Draft kit.** Nick pastes after FO blast. No publish pressure from this file. No merge. No paid Connects, boosts, featured candidate, or ads.

Official maps: [edit job profile](https://help.wellfound.com/article/773-how-do-i-edit-my-candidate-profile) · [edit public profile](https://help.wellfound.com/article/818-how-do-i-edit-my-public-profile) · [who can see what](https://help.wellfound.com/article/758-profiles).

Copy lives in [WELLFOUND-PASTE.md](./WELLFOUND-PASTE.md). Checkbox pass: [FIELD-CHECKLIST.md](./FIELD-CHECKLIST.md).

## 0. Two profiles, one account

| Surface | URL / path | Who sees it |
| --- | --- | --- |
| Jobs Profile editor | Avatar → **Edit Profile**, or [wellfound.com/profile/edit](https://wellfound.com/profile/edit) | Recruiters, only if status is **Open to Offers** or **Ready to Interview** |
| Recruiter preview | Jobs Profile toolbar → **Overview** | What companies see in candidate search |
| Public Profile | Jobs Profile → **View Public Profile** | Anyone. Does **not** mean you are job-hunting |
| Preferences | [wellfound.com/profile/edit/preferences](https://wellfound.com/profile/edit/preferences) | Search filters (job type, remote, salary, locations) |
| Search status shortcut | [wellfound.com/jobs](https://wellfound.com/jobs) → dropdown **left of avatar** | Same visibility flag as Preferences |

Fill the Jobs Profile. Public Profile reuses many of those fields.

---

## 1. Open the editor (2 minutes)

1. Sign in at [wellfound.com](https://wellfound.com).
2. Click your **avatar** (top right).
3. Click **Edit Profile**.
4. Ignore any **Boost**, **Connects**, **Get more views**, or upgrade modal. Close it.

---

## 2. Public header (name · LA · proof link)

1. From the Jobs Profile, click **View Public Profile**.
2. Click **Edit** to the right of the photo ([name / image / slug / socials](https://help.wellfound.com/article/811-user-profile-how-to-change-the-name)).
3. Paste from the paste pack:
   - Name → `Nick Trevino`
   - Username → `nick-trevino`
   - Location → `Los Angeles, California, United States` (pick the preload)
   - Website → `https://feedback-ops-copilot.vercel.app`
4. **Save** (top right).

If a **Headline** / tagline box exists on this screen, paste the locked headline. If not, skip — it goes on the experience Title.

---

## 3. About + role dropdowns

1. Still on Public Profile, click **Edit** next to **About** (Wellfound jumps you to the Jobs Profile About fields).
2. Based → `Los Angeles`.
3. Primary role → `Software Engineer` (or Full Stack if that exact option exists).
4. Years of experience → Nick’s real number.
5. Open to roles → Software Engineer (+ Full Stack only if listed).
6. Brief bio → **About A** (short lock). Use **About B** only if the box is clearly a long-form field.
7. Save.

---

## 4. Skills

1. Jobs Profile → **Profile** (or the Skills block on [profile/edit](https://wellfound.com/profile/edit)).
2. Add the eight locked skills **in order**. Choose preload tags when they appear.
3. If `AI agents`, `Cursor`, or `API integration` have no tag, skip that tag — the bio already carries the words.

---

## 5. Work experience (Applied AI Ops)

1. Jobs Profile → **+ Add Work Experience** ([experience help](https://help.wellfound.com/article/798-how-do-i-edit-my-work-experience)).
2. Company → `Applied AI Ops`. Create it if missing. Do not attach a different company.
3. Title → locked headline.
4. Type → **Contract**.
5. Dates + **I currently work here**.
6. Description → experience block from the paste pack.
7. Save.

Public Profile **EXPERIENCE** edits the same records.

## 6. Project (proof URL)

1. Public Profile → **Project Title** (expand) ([projects help](https://help.wellfound.com/article/818-how-do-i-edit-my-public-profile)).
2. Title → `Feedback Ops Copilot`.
3. Link → `https://feedback-ops-copilot.vercel.app`.

Optional: Achievements block on the Jobs Profile (one paragraph in the paste pack).

## 7. Preferences (contract + remote, no salary)

Go to [wellfound.com/profile/edit/preferences](https://wellfound.com/profile/edit/preferences). The page autosaves (**Saved!** top right).

1. **Job search** → **Open to Offers** (use **Ready to Interview** only if Nick wants a louder signal). Never **Closed to Offers** if he wants inbound.
2. **US work authorization** → facts only.
3. **Job type** → primary **Contract**. Leave Full-time / Internship / Cofounder unchecked ([job-type help](https://help.wellfound.com/article/1036-how-do-i-adjust-what-job-type-i-am-looking-for-such-as-full-time-contract-internship-or-cofounder)).
4. **Locations** → `Los Angeles` ([locations help](https://help.wellfound.com/article/1037-how-do-i-set-the-locations-i-am-open-to-working-in-within-my-profile)).
5. Check **Open to Working Remotely** → **Remote only** ([remote help](https://help.wellfound.com/article/1038-how-do-i-set-the-remote-preferences-for-my-profile)).
6. **Desired Salary** → leave blank. That box is **annual**, not `$/hr` ([salary help](https://help.wellfound.com/article/1039-how-do-i-set-the-desired-salary-in-my-profile)). Rate options stay in the paste pack until Nick confirms.
7. Company size → optional.

You can set the same search status from [wellfound.com/jobs](https://wellfound.com/jobs) (dropdown left of avatar).

## 8. Culture → Looking for

1. Jobs Profile toolbar → **Culture**.
2. **Describe what you are looking for in your next job** → paste the Looking for block.
3. Skip the rest unless Nick wants the optional culture picks.

## 9. Preview, then stop

1. Jobs Profile → **Overview** — recruiter view.
2. **View Public Profile** — public view.
3. Confirm: headline or experience Title, About, eight skills, proof project, Contract + Remote only, salary empty, no boost badge.
4. **Stop.** Do not apply to a stack of jobs from this kit. Do not buy Connects. Do not run Amplemarket. FO Contra outbound is Parallel.

## FAQ

**The UI labels differ from this doc.**  
Wellfound still groups the same four Jobs Profile tabs: Profile, Resume, Preferences, Culture ([March 2023 job-profile guide](https://help.wellfound.com/article/773-how-do-i-edit-my-candidate-profile)). Match by meaning. If a Headline field appeared in a redesign, that is where the locked headline goes.

**Should I set Ready to Interview after the FO blast?**  
Default **Open to Offers**. Switch only if Nick wants recruiters to treat him as immediately bookable.

**Can I paste the $75–$120 range into Desired Salary?**  
No. Unconfirmed, and the field is annual.

**Do I need a resume upload?**  
No. Typed experience + skills are what search uses.

**Does this send Contra messages?**  
No. Profile copy only.
