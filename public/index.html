The loop

Same HITL contract as the FO mock

1. PasteClient message, form JSON, or ticket. Empty body holds.
2. ClassifyBug / Feature / Billing / Praise / Ambiguous + one-line summary.
3. UpsertInbox row. Related Task with next action and reply draft.
4. GateApproval needed stays on. Nothing sends.
